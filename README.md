# AidConnect
Microservices-based community assistance platform.

## Microservices Structure
- `api-gateway`
- `auth-service` / `user-service`
- `donation-service`
- `request-service`
- `notification-service`
- `admin-service`

## Tech Stack
- **Database:** MongoDB
- **Backend / Microservices:** Node.js, Express
- **Frontend / UI:** HTML, CSS, JavaScript
